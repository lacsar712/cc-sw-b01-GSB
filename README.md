# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

## 状态流转

| 状态 | 含义 | 实测可否改 |
|------|------|-----------|
| pending | 待处理（仍排队，未领取） | 校准员可改并重投 |
| processing | 领取中 | 不可改 |
| done | 已结案 | 不可改 |

## 重投台

顶栏「重投台」打开弹框（不占路由、不算页面）：待处理列表 + 点选行后框内分「改实测区」与「重投履历」两块。

- 校准员：仅对仍排队未领取（pending）的任务可改实测；确认后服务端在同一事务里写改前/改后履历（requeue_logs）。
- 领取中（processing）与已结案（done）：接口返回 409，实测不可再改。
- 巡检员（inspector）：可看重投履历，不可改实测（接口返回 403）。

领取进程时序可用环境变量调节：`WORKER_MIN_PENDING_SECONDS`（待处理最短停留，默认 12 秒，即改实测窗口）、`WORKER_PROCESS_SECONDS`（领取中停留，默认 2 秒）。

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 再提交超差样条，先待处理再出超差。
3. inspector 不能提交。
4. 重投台：calibrator 先投一笔进待处理，顶栏进「重投台」点选该行，在改实测区把实测拉远离标称（如 587.56 → 588.20）并确认；重投履历块出现改前/改后记录。
5. 等领取中→已结案，最终结论为超差，履历仍可见改前改后；此时改实测区提示不可再改。
6. inspector 登录进重投台：履历可见，改实测区不可编辑。
