# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

待处理任务允许校准员改实测后重投：顶栏进「重投台」，待处理行带改实测区，确认重投后服务端留下改前改后履历；重投履历按任务分块展示，任务详情在台内塞框查看（不算页面）。领取中与已结案的任务不可再改；巡检员可看履历但不可改实测。

## 状态流转

待处理（pending，排队中可改实测）→ 领取中（claimed，不可改）→ 已结案（done，不可改）。
入队或重投后有约 5 秒领取宽限（`CLAIM_GRACE_SECONDS`），宽限内可改实测重投。

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/login | 登录 |
| GET | /api/jobs | 任务列表 |
| POST | /api/jobs | 提交校准（仅校准员） |
| GET | /api/jobs/{id} | 任务详情 |
| POST | /api/jobs/{id}/resubmit | 待处理改实测重投（仅校准员，服务端留改前改后履历） |
| GET | /api/jobs/{id}/events | 该任务重投履历 |
| GET | /api/events | 全部重投履历（带灯种标称） |
